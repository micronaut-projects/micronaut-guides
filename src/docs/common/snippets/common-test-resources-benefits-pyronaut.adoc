=== Micronaut Test Resources Goals

https://melix.github.io/blog/2022/08/micronaut-test-resources.html[Micronaut Test Resources] is designed around these goals:

* **zero-configuration**: without adding any configuration, test resources are started and the application is configured to use them. Configuration is only required for advanced use cases.
* **isolation**: test resources never leak into your application's dependencies.
* **compatible with native executables**: test resources are also available when you run tests against a native executable.
* **easy to use**: `pyronaut test` starts the test resources service and works out the container configuration for you.
* **extensible**: you can implement your own test resources when the built-in ones do not cover your use case.
* **technology agnostic**: most test resources use Testcontainers under the hood, but any other technology can create resources.

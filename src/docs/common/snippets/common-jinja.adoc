The `views-jinjava` feature uses Micronaut Views' https://micronaut-projects.github.io/micronaut-views/latest/guide/#jinjava[Jinjava integration] to render Jinja templates from Python dictionaries.

Add the Jinjava dependency:

dependency:micronaut-views-jinjava[groupId=io.micronaut.views]

Configure HTML as the default template extension:

resource:application.toml[tag=jinja]

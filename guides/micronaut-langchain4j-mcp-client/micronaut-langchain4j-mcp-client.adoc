common:header.adoc[]

The https://modelcontextprotocol.io[Model Context Protocol (MCP)] lets applications expose tools to language models over a standard protocol. In this guide, you will connect a https://docs.langchain4j.dev/tutorials/ai-services[LangChain4j AI service] to the tools of an MCP server with https://micronaut-projects.github.io/micronaut-mcp/latest/guide/#clientLangchain4j[Micronaut MCP Client LangChain4j], so that the language model can call them.

The application uses the MCP server that you build in the guideLink:micronaut-mcp-diskspace-http[Disk Space MCP Server with Streamable HTTP transport] guide, which exposes a `freeDiskSpace` tool. The tests start their own MCP server, and replace the language model with a scripted one, so they need neither the MCP server of the other guide nor a language model.

common:requirements.adoc[]
* https://ollama.com[Ollama] installed, with a model that supports tools, to run the application. For example, run `ollama pull llama3.2`.
* The application of the guideLink:micronaut-mcp-diskspace-http[Disk Space MCP Server with Streamable HTTP transport] guide, to run the application.

== Dependencies

:dependencies:

Add the https://micronaut-projects.github.io/micronaut-mcp/latest/guide/#clientLangchain4j[Micronaut MCP Client LangChain4j] dependency. The application calls the MCP server at runtime, so use the `compile` scope:

dependency:micronaut-mcp-client-langchain4j[groupId=io.micronaut.mcp]

The tests start an MCP server. Add the https://micronaut-projects.github.io/micronaut-mcp/latest/guide/#serverJavaSdk[Micronaut MCP Server Java SDK] dependency with the `test` scope:

For every client in the `micronaut.mcp.client.http` configuration, Micronaut MCP registers a LangChain4j `McpClient` bean, qualified by the name of the client. It also registers an `McpToolProvider` bean, which exposes the tools of all the MCP clients to LangChain4j.

== Wire the MCP Tools

An `AiServiceCustomizer` bean customizes the creation of an AI service. Use it to give the MCP tool provider to the AI service:

source:AssistantCustomizer[]

callout:singleton[]
<.> The type argument of `AiServiceCustomizer` selects the AI service to customize.
callout:constructor-di[arg0=McpToolProvider]
<.> Register the tool provider with the LangChain4j `AiServices` builder. When the model requests a tool, the tool provider finds the MCP client that exposes it and calls the MCP server.

NOTE: Micronaut LangChain4j 2.4.0 configures `ToolProvider` beans, such as the `McpToolProvider` bean, automatically, and adds an `mcpClients` member to `@AiService` to select the MCP clients of an AI service. With Micronaut LangChain4j 2.4.0, you do not need the customizer.

== Running the Application

Start the application of the guideLink:micronaut-mcp-diskspace-http[Disk Space MCP Server with Streamable HTTP transport] guide, which listens on port 8080.

:exclude-for-build:maven,pyronaut

Then, start this application with the `./gradlew run` command. It listens on port 8081.

:exclude-for-build:

:exclude-for-build:gradle,pyronaut

Then, start this application with the `./mvnw mn:run` command. It listens on port 8081.

:exclude-for-build:

:exclude-for-build:gradle,maven

Then, start this application with the `pyronaut dev` command. It listens on port 8081.

:exclude-for-build:

Make sure Ollama is running and ask a question:

[source,bash]
----
curl -X POST -H 'Content-Type: text/plain' -d 'How much free disk space do I have?' localhost:8081/assistant
----

The model calls the `freeDiskSpace` tool of the MCP server and answers with the free disk space of your computer.

common:header.adoc[]

https://mateu.io[Mateu] is an open-source (Apache 2.0) library that renders business UIs from plain Java classes. You declare a screen as a class annotated with `@UI`, and Mateu turns it into a complete web UI: forms, listings with search and paging, create and edit pages with validation, and the application shell with its menu. You write no HTML, CSS or JavaScript.

In this guide, you will build a small product catalogue: an app shell with a menu, and a full CRUD over a Java record, rendered with the https://redwood.oracle.com[Oracle Redwood] design system.

=== Mateu dependencies

Add the Mateu runtime for Micronaut, the Redwood renderer and the Mateu annotation processor:

:dependencies:

dependency:mateu-micronaut[groupId=io.mateu,version=@mateu-micronautVersion@]
dependency:mateu-redwood[groupId=io.mateu,version=@mateu-redwoodVersion@,scope=runtimeOnly]
dependency:mateu-annotation-processor-micronaut[groupId=io.mateu,version=@mateu-annotation-processor-micronautVersion@,scope=annotationProcessor]

:dependencies:

The annotation processor generates a Micronaut controller for every class annotated with `@UI`. The Redwood renderer is a set of static assets packaged in the `mateu-redwood` jar, which the Mateu runtime serves: no configuration is needed.

common:graal-with-plugins.adoc[]

Mateu needs no reflection configuration in a native executable: `mateu-core` ships a GraalVM feature that registers Mateu's classes and your view models, records and enums for reflection, and the renderer's assets as resources. Start the native executable and open `http://localhost:8080`: the same UI, served by a process that starts in milliseconds.

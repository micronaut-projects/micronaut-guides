Add the following required dependencies:

:dependencies:

=== UserController

Create a controller to render the login and signup pages:

source:controllers/UserController[]

:exclude-for-languages:python
callout:secured-anonymous[]
callout:controller[arg0=/user]
callout:form-generator[]
callout:produces-html[]
callout:get[arg0=auth,arg1=/auth]
callout:view[]
callout:get[arg0=authFailed,arg1=/authFailed]
callout:executes-on[]
callout:consumes[]
callout:post[arg0=signUpSave,arg1=/signUp]
callout:get[arg0=signUp,arg1=/signUp]
callout:on-error[]
callout:on-error-request[]
:exclude-for-languages:
:only-for-languages:python
<1> Annotate with `io.micronaut.security.Secured` to configure secured access. The `SecurityRule.IS_ANONYMOUS` expression will allow access without authentication.
<2> The login, login failure, signup form, and signup save routes live under `/user`.
<3> `RegisterService` is injected to create new database users.
<4> Set the response content-type to `HTML` with the `@Produces` annotation.
<5> Responds to GET requests at `/auth`.
<6> Use `@View` to specify which template renders the response.
<7> Responds to GET requests at `/authFailed`.
<8> Blocking database operations are offloaded to a blocking thread pool.
<9> The signup route consumes form-encoded data.
<10> Responds to POST requests at `/signup`.
<11> The request is available when the error response is created.
<12> Responds to GET requests at `/signup`.
<13> Invalid signup requests return the signup page with an error message.
:only-for-languages:

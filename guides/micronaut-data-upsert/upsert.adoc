An https://micronaut-projects.github.io/micronaut-data/latest/guide/#upserts[upsert] is a native database operation that inserts a row when no matching row exists, or updates the existing row when a match is found.
Doing this in a single statement, instead of a "find, then insert or update" sequence, avoids a race condition: two concurrent requests cannot both decide the row is missing and both attempt an insert.

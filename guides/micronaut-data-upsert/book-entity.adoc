=== Entity

Create a `Book` entity:

source:Book[]

callout:serdeable[]
callout:mapped-entity[]
callout:mapped-entity-id[]
:exclude-for-languages:groovy,kotlin,python
callout:nullable-record-id[]
:exclude-for-languages:

NOTE: The `id` is not annotated with `@GeneratedValue`. By default, Micronaut Data uses the entity identity as the upsert conflict target, so the caller must supply the identity value. Upserts that rely on the default identity conflict target reject entities with generated identities.

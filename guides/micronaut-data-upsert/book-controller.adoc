=== Controller

Create a controller which uses the upsert method both to create and to update a book:

source:BookController[]

callout:controller[arg0=/books]
callout:constructor-di[arg0=BookRepository]
callout:post[arg0=save,arg1=/books]
callout:at-status[]
callout:body[]
<.> The same repository method inserts or updates the row, depending on whether a book with the supplied `id` already exists.
callout:put[arg0=update,arg1=/books]

:only-for-languages:python
The controller is annotated with `@ExecuteOn(TaskExecutors.BLOCKING)` so the blocking database calls run on the blocking executor instead of the event loop.
:only-for-languages:

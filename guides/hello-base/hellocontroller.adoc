=== Controller

:exclude-for-languages:python

To create a microservice that responds with "Hello World", you first need a controller.

Create a controller:

source:HelloController[]

callout:controller[arg0=/hello]
callout:get[arg0=index,arg1=/hello]
callout:text-plain[]
<.> A String "Hello World" is returned as the result.

:exclude-for-languages:java,groovy,kotlin

Create a route:

source:HelloController[]

callout:get[arg0=index,arg1=/hello]
callout:text-plain[]

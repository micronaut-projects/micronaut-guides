common:header.adoc[]

Language models can only produce text. With https://docs.langchain4j.dev/tutorials/tools[tools] (also known as function calling), a model can ask your application to run code, for example to look up data that the model does not know, and then use the result in its answer.

In this guide, you will expose a method of a Micronaut bean as a LangChain4j tool, give it to a https://docs.langchain4j.dev/tutorials/ai-services[LangChain4j AI service], and test that the AI service runs the tool, without calling a language model in the tests.

common:requirements.adoc[]
* https://ollama.com[Ollama] installed, with a model that supports tools, to run the application. For example, run `ollama pull llama3.2`.

== Tools

A tool is a method annotated with LangChain4j's `@Tool` annotation. The library of this guide knows how many copies of each book it can lend:

source:BookTools[]

:exclude-for-languages:python
callout:singleton[]
<.> The data is hard-coded for the purpose of this example. A real application would read it from a database or call another service.
<.> The `@Tool` value describes the tool to the model. The model decides when to call the tool based on this description.
<.> The `@P` annotation names and describes the parameter. The model sends the arguments of the call as JSON, using these names.
:exclude-for-languages:

:only-for-languages:python
<1> The data is hard-coded for the purpose of this example. A real application would read it from a database or call another service.
<2> Use `jakarta.inject.Singleton` to designate a class as a singleton.
<3> LangChain4j reads the `@Tool` annotations reflectively from the Java class that Pyronaut generates for the Python class. `@AllowsReflection` keeps the annotations available at runtime.
<4> The `@Tool` annotation names the tool and describes it to the model. The model decides when to call the tool based on this description.
<5> The `@P` annotation names and describes the parameter. The model sends the arguments of the call as JSON, using these names.

:exclude-for-languages:

:only-for-languages:python
<1> Annotate the class with `@AiService` to register a LangChain4j AI service as a bean. The `tools` member lists the beans whose `@Tool` methods the AI service can call.
<2> LangChain4j reads the annotations of the AI service reflectively. `@AllowsReflection` keeps them available at runtime.
<3> `@SystemMessage` sets the instructions sent to the model with every request.
:only-for-languages:

When the model answers with a request to execute a tool, the AI service invokes the method of the bean, sends the result back to the model, and returns the final answer of the model.

== Tests

<.> The AI service executed the tool, and the answer contains the result of the tool.
<.> The AI service sent the specification of the tool, built from the `@Tool` and `@P` annotations, to the model.

Make sure Ollama is running and ask a question:

[source,bash]
----
curl -X POST -H 'Content-Type: text/plain' -d 'How many copies of Dune can I borrow?' localhost:8080/library
----

The model calls the tool and answers that the library can lend three copies.
